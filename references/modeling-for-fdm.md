# 為了好印而改模型

## 交付前的檢查清單
- [ ] 每次修改都開**新版本資料夾**（`vNN-簡短說明`），保留舊版
- [ ] 改之前先確認規格和實際模型（零件位置、偏心的板子、要遮住的元件），不要用猜的
- [ ] 沒有多餘的結構：殘留的小台階、奇怪的凸出物、破碎的小塊。優先用乾淨的形狀（例：梯形塊＋一個螺母孔），導角跟旁邊一致
- [ ] 網格封閉、單一實體（或預期的實體數）
- [ ] **干涉檢查＋裝配路徑**：沒有交集還不夠，要確認放得進去、鎖得起來、不會把力量壓到脆弱零件上
- [ ] 刻字、細縫先做**線寬檢查**（見下方）
- [ ] 跟舊版比較，確認只有預期的地方改變（例：計算「孔區外的體積變動 = 0」）

## 線寬（0.4mm 噴嘴）
- 筆畫和縫都以 **≥ 0.45mm** 為目標；0.35–0.4 勉強可以印，要開 Arachne、外牆放慢。
- 陰刻（刻字）：太細的刻線會被填平，刻線之間太薄的牆會消失，兩種都要量。
- 用形態學量：`thin = g − opening(g, w)`（筆畫 < w）、`gap = closing(g, w) − g`（縫 < w）。
- **整體外擴會吃掉密集字的鏤空**（例：「廢」「製」外擴 0.1–0.2 就糊了）。比較好的做法：
  - 放大（字形不變，最有效）
  - 只在空間夠的地方加粗；點陣字可以先還原成格子，以「整條直邊」為單位決定加不加粗，避免同一條邊出現段差
  - 撐開字腔，或加大字距
  - 「@」這類符號：先撐開內縫，再只往外加粗外圈；或以接點為中心縮小內部的字母
- 尺寸實在放不下時，誠實說明物理極限（例：點陣字在固定寬度下，點距最多只能到多少）。

- **字洞印不出來時，整片等比放大，不要撐開字腔或改筆畫**：品牌字、logo 的比例不能動。要改字形一定先問。
- 整片放大時只動 XY，Z 不動，分色薄片才會繼續對齊切片層（`scripts/bambu_3mf_scale_xy.py`）。
- 功能孔不跟著放大：先用稍大的柱體把放大後的孔補滿，再在放大後的孔心用原直徑切孔。

## 高度
- 刻字深度、頂面高度設成層高的整數倍（見 bambu-slicing.md）。
- 陰刻要給手工上色用時，0.4–0.5mm 比較好填色。

## 列印方向和層紋
- 彈片／ㄈ 型切縫：連接處不能跟層紋同方向（受力時會沿層剝開）。一邊全斷，另一邊全連。
- 倒扣列印時，內部的固定結構做到跟外殼一樣高，支撐比較不會亂長。
- 朝下的懸空台階改成約 45° 漸出斜面，就不用支撐。

## 模型板（runner／gate 造型）
- 澆口＝靠框的粗支幹＋靠零件的短細頸。零件變小時，**延長粗的那段**，細頸維持原長度，不要拉成一條長細線（容易斷）。
- 背對背榫合的雙面件：B 面是 A 面的鏡像，但**文字要保持可閱讀**，靠孔的文字位置也要跟著鏡像。
- 圓柱榫和孔要考慮印表機的圓孔補償（見 bambu-slicing.md）。

## 外殼結構（脆弱的螢幕、PCB）
- 找出受力路徑，例如「鎖螺絲 → 後殼頂到排針 → 板子往前 → LCD 被前框擠壓」。名義間隙設 0 很危險。
- 正確做法：保護片由殼體承托；PCB 用安裝孔獨立固定；前後殼的螺柱端面互相頂住當作硬限位，鎖緊的力量不經過 PCB 和 LCD。
- 不要塞泡棉補救；先用假件試裝。
- **板子斜插時卡在固定肋（實測）**：先問清楚裝法（例如 USB 端先斜插、再壓另一端），以插入口當轉軸，每 1° 模擬一次板子到肋的間隙；坐定時間隙夠，不代表壓下去的過程不會卡（V56 坐定 0.27，壓到 6° 時剩 0）。修法是把肋的自由端斜切，一路收到原本的定位面，坐定時的定位不變（V57 每個角度 ≥ 0.27，實裝不卡）。

## 嵌件（NFC 貼紙、磁鐵）
- **量產不要做「列印中暫停放嵌件」的封閉槽**：暫停太久會脫落，失敗時嵌件也跟著報廢，而且放進去之後沒辦法先測試。
- 改成**從看不到的那一面開放的槽＋獨立薄蓋**，印完確認成功再裝：
  - 槽分兩段：下段放嵌件（例：Ø25 貼紙 → Ø25.7 × 0.6），上段比下段寬一圈形成台階（例：Ø26.6 × 1.0），蓋子放在台階上
  - 蓋子靠台階定位，所以頂面一定齊平，**跟嵌件厚度無關**
  - 其他零件（電池）黏在蓋子上，不會直接黏到嵌件
- 外皮厚度（嵌件到外觀面的距離）維持不變，NFC 的讀取距離就不會變。
- 嵌件上方肉厚不夠時（例：只有 1mm），旋轉卡扣做不出來；要加厚就會擠到裡面的零件，先量空間。
- 黏蓋子：**透明 PETG 不要用瞬間膠**（揮發會讓表面白化，從外面看得到）。用薄雙面膠或 B-7000 這類透明軟膠，點在台階上，不要點到嵌件。

## 從現成網格改模型（manifold3d／trimesh）
- 先**弄清楚原始結構**：是不是有底板、有沒有澆口、零件之間怎麼連，用剖面圖和實體數確認，不要假設。
- 清除舊特徵時，範圍要比輪廓大一點（舊零件底部常常微微外張）；重建後掃描舊位置有沒有殘留的細刺。
- 新加的實體不要跟舊實體的面剛好重疊（共面），容易產生破面；讓它稍微窄一點或錯開。
  - 例：要把舊的封閉空腔（多邊形 r12.8）挖開，用同半徑的圓柱去減會留碎面 → 圓柱半徑加 0.05（r12.85）就乾淨了。
- manifold 的輸出轉 trimesh 時用 `process=False`：預設的頂點合併會把封閉網格弄破。
- **檢查 STL 存檔後重新讀入**的結果，不是只看記憶體裡的網格：STL 是 float32，很接近的頂點會被合併，存檔前封閉、讀回來就破了。破了就用 `set_tolerance(tol).simplify(tol)` 從 1e-6 往上試。
- 原檔有封閉空腔時，manifold 的 `genus()` 會少 1（空腔算一個額外的殼）。挖開後 genus 變回正常值，不代表多了一個洞。
- 改之前先確認列印檔和組裝檔的關係（例：PRINT 檔＝組裝檔繞 X 轉 180° 再貼地），新版照同樣方式產生，不要另外轉。
- 從切片輪廓取出的多邊形，先 simplify 去掉重複點再擠出。
- 點陣字斜角相接的地方，合併後會變成「捏點」，刻字前要補一個小方塊連接。
- 抓圖案時要「外框減掉裡面的島」，不然眼睛、字腔會變成實心。
- 依面積判斷零件的門檻，整體縮放後要跟著乘上倍率的平方。

## 像素字型：只靠斜角相接的筆畫會斷（2026-11-10 實測）
- 像素風 logo 常見筆畫只在斜角碰一個點（例：C 的右端、O 的四角、B 右側凸塊）。接點寬度 0，FDM 一定斷開，印章上 C 會像 O、B 會像 E。
- **放大、Arachne、改線寬、XY 內縮都救不了**（寬度 0 放大還是 0）。之前「放大 130%」的建議只考慮了筆畫粗細，是錯的。
- 解法：在每個斜角接點補一個小方塊（0.45mm 有效；0.3mm 太細會被切片軟體略過），整體比例不動，只改接點。改 logo 接點前要先問使用者。
- 偵測：截頂面輪廓 → `buffer(-0.03)` 後會分開的地方就是外部斜角；同一塊內部的斜角（例如 B）要另外用頂點四象限「棋盤格」測試抓。
- 驗證：用 E 值換算線寬，把頂層走線畫成實心足跡（不是只畫線），才看得出筆畫有沒有連起來。

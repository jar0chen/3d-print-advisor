# 為了好印而改模型

## 交付前的檢查清單
- [ ] 每次修改都開**新版本資料夾**（`vNN-簡短說明`），保留舊版
- [ ] 改之前先確認規格和實際模型（零件位置、偏心的板子、要遮住的元件），不要用猜的
- [ ] 沒有多餘的結構：殘留的小台階、奇怪的凸出物、破碎的小塊。優先用乾淨的形狀（例：梯形塊＋一個螺母孔），導角跟旁邊一致
- [ ] 網格封閉、單一實體（或預期的實體數）
- [ ] **干涉檢查＋裝配路徑**：沒有交集還不夠，要確認放得進去、鎖得起來、不會把力量壓到脆弱零件上
- [ ] 刻字、細縫先做**線寬檢查**（見下方）
- [ ] 跟舊版比較，確認只有預期的地方改變（例：計算「孔區外的體積變動 = 0」）

## 線寬（0.4mm 噴嘴）
- 筆畫和縫都以 **≥ 0.45mm** 為目標；0.35–0.4 勉強可以印，要開 Arachne、外牆放慢。
- 陰刻（刻字）：太細的刻線會被填平，刻線之間太薄的牆會消失，兩種都要量。
- 用形態學量：`thin = g − opening(g, w)`（筆畫 < w）、`gap = closing(g, w) − g`（縫 < w）。
- **整體外擴會吃掉密集字的鏤空**（例：「廢」「製」外擴 0.1–0.2 就糊了）。比較好的做法：
  - 放大（字形不變，最有效）
  - 只在空間夠的地方加粗；點陣字可以先還原成格子，以「整條直邊」為單位決定加不加粗，避免同一條邊出現段差
  - 撐開字腔，或加大字距
  - 「@」這類符號：先撐開內縫，再只往外加粗外圈；或以接點為中心縮小內部的字母
- 尺寸實在放不下時，誠實說明物理極限（例：點陣字在固定寬度下，點距最多只能到多少）。

## 高度
- 刻字深度、頂面高度設成層高的整數倍（見 bambu-slicing.md）。
- 陰刻要給手工上色用時，0.4–0.5mm 比較好填色。

## 列印方向和層紋
- 彈片／ㄈ 型切縫：連接處不能跟層紋同方向（受力時會沿層剝開）。一邊全斷，另一邊全連。
- 倒扣列印時，內部的固定結構做到跟外殼一樣高，支撐比較不會亂長。
- 朝下的懸空台階改成約 45° 漸出斜面，就不用支撐。

## 模型板（runner／gate 造型）
- 澆口＝靠框的粗支幹＋靠零件的短細頸。零件變小時，**延長粗的那段**，細頸維持原長度，不要拉成一條長細線（容易斷）。
- 背對背榫合的雙面件：B 面是 A 面的鏡像，但**文字要保持可閱讀**，靠孔的文字位置也要跟著鏡像。
- 圓柱榫和孔要考慮印表機的圓孔補償（見 bambu-slicing.md）。

## 外殼結構（脆弱的螢幕、PCB）
- 找出受力路徑，例如「鎖螺絲 → 後殼頂到排針 → 板子往前 → LCD 被前框擠壓」。名義間隙設 0 很危險。
- 正確做法：保護片由殼體承托；PCB 用安裝孔獨立固定；前後殼的螺柱端面互相頂住當作硬限位，鎖緊的力量不經過 PCB 和 LCD。
- 不要塞泡棉補救；先用假件試裝。
- **板子斜插時卡在固定肋（實測）**：先問清楚裝法（例如 USB 端先斜插、再壓另一端），以插入口當轉軸，每 1° 模擬一次板子到肋的間隙；坐定時間隙夠，不代表壓下去的過程不會卡（V56 坐定 0.27，壓到 6° 時剩 0）。修法是把肋的自由端斜切，一路收到原本的定位面，坐定時的定位不變（V57 每個角度 ≥ 0.27，實裝不卡）。

## 從現成網格改模型（manifold3d／trimesh）
- 先**弄清楚原始結構**：是不是有底板、有沒有澆口、零件之間怎麼連，用剖面圖和實體數確認，不要假設。
- 清除舊特徵時，範圍要比輪廓大一點（舊零件底部常常微微外張）；重建後掃描舊位置有沒有殘留的細刺。
- 新加的實體不要跟舊實體的面剛好重疊（共面），容易產生破面；讓它稍微窄一點或錯開。
- 從切片輪廓取出的多邊形，先 simplify 去掉重複點再擠出。
- 點陣字斜角相接的地方，合併後會變成「捏點」，刻字前要補一個小方塊連接。
- 抓圖案時要「外框減掉裡面的島」，不然眼睛、字腔會變成實心。
- 依面積判斷零件的門檻，整體縮放後要跟著乘上倍率的平方。
